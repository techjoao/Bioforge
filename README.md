# BioForge

**A privacy-first, open-source visual builder for personal biography websites.**

BioForge is a small, browser-based editor for building a personal biography page without writing code. The project is designed around one non-negotiable principle: **the app does not collect or transmit personal data.**

## Privacy principles

- No accounts, user database, analytics, telemetry, advertising trackers, or tracking pixels.
- Biography content is processed in the browser and is never uploaded to a BioForge server.
- No third-party APIs, remote fonts, or externally hosted scripts are required.
- Draft saving is local to the current browser/device and can be cleared by the user.
- Exported websites are static files that the user can host wherever they choose.

A hosting provider may independently process technical request data when a published website is visited. That is separate from BioForge's application code and should be considered when choosing a host.

## Current status

The first version is a static client-side editor. Open `index.html` in a modern browser; no build step or backend is needed.

## Run locally

1. Download or clone this repository.
2. Open `index.html` in your browser.

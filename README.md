# BioForge

**A privacy-first, open-source visual builder for personal biography websites.**

BioForge Studio lets you create a personal page with a live preview, without writing code. It is a static, browser-based app: no account, backend, or BioForge server is needed.

## Features

- Live page preview while editing.
- Three visual directions: Noir, Editorial, and Terminal.
- Typography and background presets, plus a custom accent color.
- Optional profile image, processed locally in the browser.
- Biography, location, projects, interests, and social links.
- Local draft saving in the current browser.
- Standalone HTML export, ready to host anywhere.
- Responsive editor and page preview, including a narrow/mobile preview.

## Privacy by design

- No accounts, user database, analytics, telemetry, advertising trackers, or tracking pixels.
- Biography content and selected profile images are processed in the browser and are not uploaded to BioForge.
- No third-party APIs, remote fonts, or externally hosted scripts are required.
- Drafts are stored only in the browser's local storage on the current device.
- Exported pages are static files. If you publish them, your chosen hosting provider may independently process technical request data such as server logs.

## Run locally

1. Download or clone this repository.
2. Open `index.html` in a modern browser.

No build step, package installation, or backend is required.
